# 首页布局重构：画布区 + 输入框 + 精选作品

## 产品思路
首页的核心动作是"开始创作"，其次是"继续上次的工作"，最后是"找灵感"。所以从上到下按这个优先级排：

```text
[大字标 ArTrail + 一句引导语]
[构建 / 创建 / 互动故事 三张入口卡]   ← 缩小为一行紧凑卡片
[输入框（大）]                        ← 首屏视觉中心
[图1：画布创作  最近使用·本周热门·推荐技能]
  最近画布 (10)            查看全部 >
  [+新建画布] [画布卡] [画布卡] ...   ← 一行横向，超出可横滑
[图2：精选作品 | 创作课程]  标签切换
  4 列作品瀑布网格，悬停显示"查看"和作者 @名字
```

## 输入框交互
1. 首屏：输入框在中部，完整尺寸（附件、创作类型、模型、思考深度等菜单都在）。
2. 向下滑动：当输入框滑出视野，底部出现一个缩小的悬浮胶囊（单行："输入你的需求即可生成图片、视频…" + 发送箭头），居中贴底，带毛玻璃背景，与图2底部一致。
3. 点击胶囊 / 聚焦输入：输入框放大为完整版本，悬浮在页面底部中间，背后加淡遮罩；已输入的文字在大小两种状态之间保持同步。
4. 点击遮罩、按 Esc 或失焦且内容为空：收回为小胶囊。滑回顶部时，小胶囊消失，回到原位大输入框。

## 内容与数据
- 最近画布、精选作品均为演示内容（标题、作者、编辑时间照图示风格编写），配图用 AI 生成的游戏美术风格缩略图（约 5 张画布 + 12 张作品）。
- "画布创作 / 最近使用 / 本周热门 / 推荐技能"和"精选作品 / 创作课程"可切换高亮，暂不切换真实数据。
- 卡片点击暂无跳转（后续接入 Cloud 再做）。

## 视觉
沿用现有深色主题（图示为浅色，统一调成深色卡片、浅色文字），圆角、间距对齐图示比例。

## 技术细节
- 新组件：`recent-canvases.tsx`、`featured-works.tsx`；`home-composer.tsx` 增加 `variant: "full" | "compact"`，文字状态提升到首页共享。
- 用 IntersectionObserver 监听原位输入框是否在主滚动区内可见，决定是否显示底部胶囊；展开态用 fixed 定位 + 过渡动画（scale/opacity）。
- 更新 home-composer 测试：输入框滑出后出现胶囊，点击胶囊展开、Esc 收起。
