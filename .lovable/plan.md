# 触发一次 GitHub 同步

## 现状
项目已经连上 GitHub，但仓库里看不到代码。我这边看不到同步状态，也不能直接推送；只有项目里出现新的改动时，系统才会把代码推到 GitHub。

## 计划
1. 在项目说明文件 `roadmap.md` 里加一行很小的说明（不影响页面和功能），生成一次新的改动，让系统把全部代码推到已连接的仓库。
2. 改完后请你刷新 GitHub 仓库页面，检查设置里显示的那个分支：
   - 能看到 `src`、`package.json` 等文件，就说明同步成功。
   - 如果还是空的，打开 项目设置 → Git，看有没有"已分叉"、文件过大或推送失败之类的提示，把提示文字或截图发给我。
   - 如果有名字以 `lovable-sync` 开头的分支，代码就在那个分支里，把它合并进主分支就行。

## 说明
- 这次只改说明文件，不会影响页面效果。
- 如果设置页本身显示连接异常，需要你在设置里断开再重新连接，系统会新建一个仓库并推送全部代码。
